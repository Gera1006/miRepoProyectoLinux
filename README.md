# Repositorio de práctica
## Descripción del repositorio
En este repositorio agrego los programas desarrollados por mí para el proyecto de terminal en linux, como parte del proceso de ingreso a protecsa. Este repositorio servirá como práctica para la subida de archivos a GitHub desde mi terminal.
## Uso de Conventional Commits
Se usará la siguiente convención para commits profesionales:
| Tipo     | Uso                              |
|----------|--------------------------------------------------------|
| feat     | Para nuevas funcionalidades                            |
| fix      | Para corrección de errores                             |
| docs     | Para cambios en la documentación                       |
| style    | Para formato (espacio, com, etc)                       |
| refactor | Para mejoras de código sin cambio en la funcionalidad  |
| test     | Para agregar o mejorar pruebas   |
| chore    | Para tareas auxiliares   |
